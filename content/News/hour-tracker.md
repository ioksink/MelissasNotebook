I have written a little tool to track my own working hours. It can be make into a desktop launcher and has start/end button for working and pause. The record can be edited, but only with a note on it. At last, a monthly report excel file can be exported.

The tool is written in python. 

[Find the tool in my github.](https://github.com/ioksink/working-hour-tracker)
